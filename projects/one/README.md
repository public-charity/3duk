# Project One - Isle of Thanet explorer

A walkable/flyable Unreal Engine 5.8 model of the Isle of Thanet built from the 3duk pipeline's engine-neutral
output (EA LIDAR + OpenStreetMap, EPSG:27700/ODN), with a reusable **Streetscape** plugin that turns OSM roads,
kerbs, hedges and rail into meshes from a shared spline + profile schema, prototyped first in Blender/numpy.

Normative documents live in `docs/`: `BRIEF.md` (what and why, binding decisions in section 4), `DESIGN.md`,
`SCHEMA.md` + `schema/`, `UE_PLAN.md`, `PIPELINE_CHANGES.md`, and `STAGES.md` whose section 0 table is the only
place that says what is done.

## Layout (BRIEF.md 4.3)

```
projects/one/
  Thanet.uproject                UE 5.8 C++ project "Thanet"
  Source/Thanet/                 game module: explorer pawn, game mode (Thanet.Target.cs / ThanetEditor.Target.cs)
  Plugins/Streetscape/           the reusable plugin: runtime module Streetscape, editor module StreetscapeEditor
  Plugins/UnrealMCP/             source-only copy of the 5.8-ported UnrealMCP bridge (port 55558 here, off in commandlets)
  Config/                        DefaultEngine.ini (World Partition, DX12/SM6, Lumen/VSM), Game, Input (Enhanced), Editor
  Content/                       generated by Tools/ue scripts (the scripts are the source of truth)
  schema/                        streetscape.schema.json, profiles/*.json, examples/*.json
  Tools/blender/                 numpy geometry core + Blender renderers and their tests
  Tools/ue/                      headless editor-Python scripts and the PowerShell runner (see Tools/ue/README.md)
  Tools/build.ps1 / build.sh     UBT build of ThanetEditor Win64 Development
  docs/                          the documents above
```
