# Kent Police XC90 exploration vehicle

Superseded by `assets/KentPoliceV90`: the current playable asset is the lower V90
estate requested in the visual revision. This folder preserves the first SUV
prototype; the shared Unreal importer now imports the V90 instead.

An original, procedural **prototype** inspired by the second-generation Volvo XC90
in Kent Police service. The body is a simplified game mesh, not a production-quality
manufacturer CAD replica. No photographic textures or downloaded car models are used.

## Reference photographs and dimensions

- [Kent Police ARV XC90 GN74 ADV F11, policest1100, uploaded 13 January 2025](https://www.flickr.com/photos/83194815@N00/54265048781/).
  Visually inspected: white body, yellow bonnet, two-row blue/yellow Battenburg,
  dark window surrounds, five-spoke wheels, thin roof lightbar and vertical grille.
- [Kent Police XC90 KV22 YXO, policest1100, uploaded 17 April 2025](https://www.flickr.com/photos/83194815@N00/54458111014/).
  Additional reference link; not used as a texture.
- [Kent Police official marked fleet, 2025](https://www.kent.police.uk/SysSiteAssets/foi-media/kent/lists-and-registers/marked-vehicle-fleet/kent-police-s-marked-vehicle-fleet--2025.pdf),
  page 8, lists XC90s. This establishes recent service, not the status of an individual
  vehicle on today's date.
- [Volvo 2024 XC90 manual](https://www.volvocars.com/static/support-content/pdfs/ca_en-US_xc90_2024_UM_b18dfd7241ea9250f8e4aee7beeaf18a.pdf),
  dimensions: length 4,953 mm, wheelbase 2,984 mm, height 1,771 mm. Equipment projects
  beyond the nominal body envelope. Rear chevrons and simplified details are authored
  approximations, not a measured reconstruction of GN74 ADV's rear.

Photographs remain with their owners (Flickr primary reference: all rights reserved).
Only links are retained. The original procedural model is generated by the script.

## Rebuild

From the repository root in PowerShell:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b --python assets/KentPoliceXC90/build_xc90.py
powershell -ExecutionPolicy Bypass -File projects/one/Tools/ue/run_ue_python.ps1 -Script 10_import_police_car.py
powershell -ExecutionPolicy Bypass -File projects/one/Tools/build.ps1
```

Blender generates the editable `.blend`, body/wheel FBXs, and front/rear studio
renders. The importer checks scale and writes `import_report.json`. Unreal packages
live in `/Game/Thanet/Vehicles/KentPoliceXC90`; as elsewhere in this repository,
Content is generated and ignored by Git. Import before the first editor launch
with the new game module so the default pawn can resolve its mesh references.

## Play

Play the existing Thanet map. **E** calls the car onto nearby clear, supported ground
and switches to it. After exiting, E re-enters that same car within 8 metres.

- **W / S:** accelerate / brake and reverse.
- **A / D:** steer; steering range reduces with speed.
- **Space:** handbrake.
- **Mouse:** orbit the chase camera.
- **E:** exit when stopped, onto collision-checked ground beside the car.
- **R:** recover onto nearby supported ground (or near the last safe position).
- **L:** flashing blue lights.
- On foot, existing WASD / F fly / Shift sprint / Space jump controls remain.

The vehicle is a single-player rigid-body pawn using Chaos chassis collision,
four spring/damper contact traces and bounded tyre forces. It is an exploration
handling model, not a calibrated Volvo drivetrain simulation. It uses existing
road/landscape collision and the possessed player's World Partition streaming.
No new map bounds or teleport destinations are imposed. Existing road geometry
defects can still affect driving; recovery helps when terrain traps the chassis.
No siren audio, animated doors, detailed interior, damage or multiplayer support yet.

Regression test: `Thanet.Vehicle.PhysicsAndSwitching` in Unreal Automation.

Render the real Unreal pawn, using the imported assets, without saving a map:

```powershell
powershell -ExecutionPolicy Bypass -File projects/one/Tools/ue/run_ue_python.ps1 -Script 11_render_police_car.py -Render
```

This writes `unreal_front.png` and `unreal_rear.png` next to the Blender studio
renders. Run import and render serially with other Unreal processes closed, to
avoid Windows package file locks during reimport.
